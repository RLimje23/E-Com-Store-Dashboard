# E-Com-Store-Dashboard
## Sales and Operations Analysis:
- Domain: Retail/E-commerce
- Tools Used: Power BI

## Problem Statement:
A retail company wants to better understand its sales performance, customer behavior, and operational bottlenecks using existing data. The goal is to create an interactive dashboard that enables top-level management to track KPIs, identify sales trends, and optimize operational decisions.

## Dashboard Features:
- Slicers for filtering by Region, Segment, Category and Quarter.
- Bar charts for product and state performance (along with a map chart).
- Column chart for monthly profit trends.
- KPI Cards showing total sales, goods sold, average order value and Overall Profit.
- Donut Chart for order status distribution.
